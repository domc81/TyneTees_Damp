## Current focus

**Offline-first PWA shipped (2026-07-06).** The survey wizard is now a local-first PWA: every read/write goes to IndexedDB first, a durable op-based outbox syncs to Supabase when online, bookings prefetch today+tomorrow, a Serwist service worker serves the shell offline, photos capture locally with idempotent queued uploads, and voice notes queue for deferred transcription. Wizard-only by design — office surfaces (costing/reports/quotations/Kanban/calendar/admin) stay online. Automated tests (T1–T9, T11–T13) passed on the live deploy; **remaining: real-hardware checklist — T10 install + airplane-mode cold launch (Android primary, iPhone secondary), T14 Steve's rural field pilot, T15 real tablet.** Module map + data flow in `docs/ARCHITECTURE.md`; plan in `docs/plans/2026-07-05-offline-first-pwa-survey-wizard.md`.

**Canonical path (2026-07-05):** every survey starts as a lead in the pipeline (`/survey/new` deleted); repeat customers via existing-customer search, free revisits via Convert & Book "No survey fee". /surveys ("Projects") is purely the view/manage list.
